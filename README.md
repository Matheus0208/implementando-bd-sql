# Implementando Banco de Dados SQL 🗄️

Este repositório foi desenvolvido com o objetivo de praticar, estruturar e consolidar conhecimentos fundamentais em **Bancos de Dados Relacionais** utilizando a linguagem **SQL**. O projeto reúne desde a modelagem inicial e criação de tabelas até a construção de consultas (queries) complexas.

## 🚀 Conceitos e Recursos Abordados

O projeto está estruturado de forma a cobrir os pilares principais do SQL:

- **DDL (Data Definition Language):** Criação e modificação da estrutura do banco de dados.
  - `CREATE DATABASE` e `CREATE TABLE`
  - Definição de Constraints (`PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`)
  - Alterações estruturais com `ALTER TABLE` e remoções com `DROP`
- **DML (Data Manipulation Language):** Manipulação dos dados armazenados.
  - Inserção de registros (`INSERT INTO`)
  - Atualização de dados (`UPDATE`)
  - Exclusão de registros (`DELETE`)
- **DQL (Data Query Language):** Consultas e extração de inteligência dos dados.
  - Filtros e ordenação (`WHERE`, `ORDER BY`, `LIKE`, `IN`, `BETWEEN`)
  - Agrupamentos e funções agregadas (`GROUP BY`, `HAVING`, `COUNT`, `SUM`, `AVG`)
  - Junções de tabelas (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`)
